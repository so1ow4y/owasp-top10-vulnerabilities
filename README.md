# Отчёт по анализу уязвимостей

Данный репозиторий содержит результаты анализа уязвимостей в проектах **Eve (JS)**, **WeBob**, **Evally** и **Juice Shop**.

```bash
tree .
./
├── docs/     # Исходные отчёты сканирования
│ ├── evally-ruby-rubocop/      # Отчёты для проекта Evally (Ruby)
│ ├── eve-javascript-eslint/    # Отчёты для проекта Eve (JavaScript)
│ ├── juice-shop-dast-analysis/ # Результаты DAST-сканирования Juice Shop
│ ├── juice-shop-sast-analysis/ # Результаты SAST-сканирования Juice Shop
│ └── webob-python-flake8/      # Отчёты для проекта WeBob (Python)
├── report/   # Сводные отчёты
│ ├── REPORT.md                 # Основной отчёт в Markdown
│ ├── REPORT.csv                # Экспорт в CSV
│ └── REPORT.xls                # Экспорт в Excel
└── README.md # Этот файл
```
## Содержание отчётов

В директории `report/*` находятся сводные отчёты в трёх форматах:

1. **REPORT.md** - основной отчёт, содержащий:
   - Классификацию уязвимостей по OWASP Top 10 2021
   - Оценку уровня риска (Critical, High, Medium, Low, Info)
   - Подробное описание каждой уязвимости
   - Рекомендации по устранению
   - Ссылки на исходные отчёты сканирования

2. **REPORT.csv** - табличное представление данных в формате CSV:
   - Удобен для автоматической обработки
   - Содержит те же данные, что и REPORT.md
   - Разделитель - запятая, кодировка UTF-8

3. **REPORT.xlsx** - экспорт в Excel:
   - Полностью соответствует содержимому REPORT.md
   - Готов к печати или дальнейшему анализу
